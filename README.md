I build machine learning systems that make it to production — not notebooks that die in an `experiments/` folder.

Most of my work sits at the boundary where research meets reality: computer vision pipelines that run on messy customer data, LLM agents that do something useful rather than something demo-able, and the MLOps plumbing that keeps both alive. Versioned data, tracked experiments, containerised inference, CI/CD that actually runs on push.
